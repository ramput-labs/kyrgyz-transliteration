# Список частотных кыргызских слов: по нему to_cyrillic() восстанавливает
# ө, ү и ң, которых в английской латинице нет (см. restore.py).
# Одно слово в строке, кириллицей; строки с # игнорируются.
# Слова без ө/ү/ң тоже полезны: они подтверждают, что этих букв там нет.
#
# Звёздочка в начале строки (*үй) — предпочтительное чтение: два слова
# претендуют на одну латиницу (уй и үй -> uy), побеждает более частотное.
# Без звёздочки спорный ключ не используется совсем.
# Составные слова пишутся через дефис целиком: по частям «Ысык-Көл» от
# «ысык кол» не отличить.
